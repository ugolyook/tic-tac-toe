1)Интерфейс EmployeeUtils с методами по умолчанию и статическими методами
   Создайте интерфейс EmployeeUtils, содержащий:

статический метод printEmployees(List<Employee> list), 
который выводит каждого сотрудника на отдельной строке;

метод по умолчанию double averageSalary(List<Employee> list),
который вычисляет среднюю зарплату сотрудников в списке (если список пуст, возвращает 0.0). 
*   Реализация метода по умолчанию должна использовать потоковый API (Stream), 
но это допустимо, поскольку в главе 3 будут потоки, либо можно использовать цикл for-each. 
* Продемонстрируйте использование этих методов:
* напечатайте список с помощью EmployeeUtils.printEmployees(...); 
* выведите среднюю зарплату, вызвав метод по умолчанию через экземпляр класса, реализующего интерфейс (например, создайте пустой класс EmployeeHelper implements EmployeeUtils).
